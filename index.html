Problem and purpose

Manual payroll spreads attendance sheets, leave ledgers, tax slabs, Provident Fund, loan recoveries and settlements across separate files. That is slow and error-prone. This system connects them and puts every payroll run through an approval workflow, with each role seeing only what it needs.

Roles

Admin, HR, Accountant and Employee, with role-based access control on routes and on the API.

Architecture and request flow

  1. The Angular app signs a user in with POST /api/auth/login and stores the JWT.
  2. An HTTP interceptor attaches the token to each REST call.
  3. Spring Security checks the token and the user's role on the controller.
  4. Controllers use JPA repositories against PostgreSQL. Schema changes are versioned Flyway migrations.
  5. Mutating actions are written to the audit log, and PDFs are rendered with JasperReports.

Challenges and solutions

  • Separation of duties. People who run payroll should not approve it. I added a state-machine approval workflow and role checks on the server.
  • Data integrity. I used Flyway migrations to add unique constraints and indexes, and to make settlements immutable once finalised.
  • Silent failures. I fixed forms that reported success before the backend confirmed, so users now see real errors.
